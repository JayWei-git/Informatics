## Theory

##### XOR

- 相同为 $0$ 不同为 $1$，其实就是**无进位相加**；

  $\to$ 所以异或满足交换律和结合律；

  $\to$ 所以 $n\oplus0=n$，$n\oplus n=0$；

- $\text{if }x=y\oplus z\text{ then }z=x\oplus y$：

  等式两边同时异或一个 $y$：$x \oplus y = y \oplus z \oplus y$，而 $y \oplus y = 0$，$z \oplus 0=z$；

- 异或实现swap：

  ```cpp
  void xorSwap(int& a, int& b) {
      if (&a != &b) { // 确保不是同一个变量
          a = a ^ b;
          b = a ^ b;
          a = a ^ b;
      }
  }
  ```

  $$
  \begin{aligned}
    Step1:A'&=A \oplus B\\
    Step2:B'&= A'\oplus B= (A\oplus B) \oplus B = A\\
    Step3:A''&=A'\oplus B'=(A \oplus B)\oplus A = B
    \end{aligned}
  $$

  **WARNING**：如果两个变量指向的是同一个内存地址 (即同一个变量)，这个算法会导致变量变成 0 (因为相同数异或就是零)；

- 异或实现max：

  ```cpp
  // 不能直接相减再提取符号位，会面临溢出风险
  int max(int a, int b) {
      // 1. 获取 a 和 b 的符号位（正数/0 为 0，负数为 1）
      // 注意这是逻辑右移，负数会补1
      int sa = (a >> 31) & 1;
      int sb = (b >> 31) & 1;
      
      // 2. 判断 a 和 b 的符号是否不同
      // 不同，use_sign = 1；相同，use_sign = 0
      int use_sign = sa ^ sb;
      
      // 3. 计算 a - b 的符号位
      // 只有在 use_sign = 0(同号)时，这个差值才是有意义的
      int diff_sign = ((a - b) >> 31) & 1;
      
      // 4. 计算选择因子
      // 情况 A：异号 (use_sign == 1)，且 a 是负数 (sa == 1)，选 b
      // 情况 B：同号 (use_sign == 0)，且 a - b < 0 (diff_sign == 1)，也选 b
      // 注意异号时diff_sign可能是无意义的
      int k = (use_sign & sa) | ((~use_sign) & diff_sign);
      
      // 5. 无分支选择
      // 当 k = 1 时，-k 为 0xFFFFFFFF，结果为 b
      // 当 k = 0 时，-k 为 0x00000000，结果为 a
      return a ^ ((a ^ b) & -k);
  }
  ```

##### Bit Set

- 实现一个位图类，用各个比特标识某个数字是否存在于集合中；

  [LeetCode - 2166. 设计位集](https://leetcode.cn/problems/design-bitset/)；

  ```cpp
  // 忽略边界检查 和 浅拷贝
  class Bitset {
  public:
      Bitset(int n) : set(new int[(n + 31) / 32]()) {} // n/32向上取整，另外注意加个括号初始化为全零
      ~Bitset() { delete[] set; }
      void add(int num);
      void remove(int num);
      void reverse(int num);
      bool contains(int num);
      
  private:
      int* set;
  };
  
  void Bitset::add(int num) {
      // num / 32结果为num在set的第几个元素中
      // num % 32结果为num对应该元素的第几位
      set[num / 32] |= 1 << (num % 32); 
  }
  
  void Bitset::remove(int num) {
      set[num / 32] &= ~(1 << (num % 32));
  }
  
  void Bitset::reverse(int num) {
      set[num / 32] ^= 1 << (num % 32);
  }
  
  bool Bitset::contains(int num) {
      return ((set[num / 32] >> (num % 32)) & 1) == 1;
  }
  ```

##### add / sub / mul / div

- [LeetCode - 29. 两数相除](https://leetcode.cn/problems/divide-two-integers/);

1. add / sub：

   按位异或得所有本位和，按位与得所有进位和；

   硬件直接把上一位进位输出通过导线连到下一位进位输入；软件只能通过将进位和左移一位然后不断相加直到进位为零来模拟进位的层层传递；

   ```cpp
   typedef unsigned int uint;
   // 为啥要用uint？因为C中int没有定义左移溢出的行为
   // 其实也无所谓，反正处理的都是a，b的比特模式
   // 输入上，直接将a视为最初的本位和，b视为最初的进位和，复用逻辑
   uint add(uint a, uint b) {
       while (b != 0) {
           uint carry = (a & b) << 1;
           a = a ^ b;
           b = carry;
       }
       return a;
   }
   ```

   减就是加上加法逆元，不多说；

   ```cpp
   uint sub(uint a, uint b) {
       return add(a, add(~b, 1u));
   }
   ```

2. mul / div：

   `b` 的某一位是 `1`，就把对应的 `a` 加入答案；每轮 `a` 左移、`b` 右移，处理下一位；

   ```cpp
   // 也是处理比特模式，jie gu
   uint mul(uint a, uint b) {
       uint ans = 0;
       while (b != 0) { // b == 0说明耗尽了，乘完了
           if (b & 1u) ans = add(ans, a);
           a <<= 1; // 越界直接不要了，说明本身乘出来就会溢出
           b >>= 1; // uint右移是逻辑右移
       }
       return ans;
   }
   ```

   ```cpp
   int neg(int a) {
       return ~a + 1;
   }
   
   // 需要保证a和b不是INT_MIN
   int help(int a, int b) {
   	a = a < 0 ? neg(a) : a;
       b = b < 0 ? neg(b) : b;
       uint ans = 0;
   
       for (int i = 30; i >=0 ; i = sub(i, 1)) {
           if ((a >> i) >= b) {
               ans |= (1 << i);
               a = sub(a, b << i);
           }
       }
   
       return a < 0 ^ b < 0 ? neg(ans) : ans;
   }
   
   int div(int a, int b) {
   	if (a == INT_MIN && b == INT_MIN) return 1;
       if (a != INT_MIN && b != INT_MIN) return help(a, b);
   
       if (b == INT_MIN) return 0; // a是整数最小，b不是
   
       if (b == neg(1)) {  // 这是题目规定的，INT_MIN除-1返回INT_MAX 
           return INT_MAX; // 但我们知道实际上并不是
       }
   
       // a是INT_MIN，b不是INT_MIN也不是-1
       a = add(a, b > 0 ? b : neg(b));
       int ans = help(a, b);
       int offset = b > 0 ? neg(1), 1;
       return add(ans, offset);
   }
   ```

  int missingNumber(vector<int>& nums) {
      int xorAll = 0, xorNums = 0;
      
      for (int i = 0; i < nums.size(); ++i) {
          xorAll ^= i;
          xorNums ^= nums[i];
      }
      xorAll ^= nums.size();

##### LC260

- 题目：[LeetCode - 260. 只出现一次的数字III](https://leetcode.cn/problems/single-number-iii/description/)；
- 假设两个出现奇数次的元素为 $x$ 和 $y$；
  - 先将所有数异或，结果就是 $x\oplus y$；
  - 由于 $x$ 与 $y$ 不同，所以 $x\oplus y$ 一定有若干位为1；
  - 不妨取 $x\oplus y$ 最低位的1，则一定是 $x,y$ 其中一个在该位上为1，另一个为0；
  - 将原数组中该位为1的数全部异或起来，结果就是 $x,y$ 其中一个；
  - 再将这个结果与 $x\oplus y$ 异或一下，就得到另外一个；

> [!TIP]
>
> **LowBit —— Brian Kernighan**
>
> - 提取二进制数最低位的1；比如 00101100 提取后就是 00000100；
> - 方法：取反+1后再与原数按位与；00101100 $\to$取反$\to$ 11010011 $\to$加1$\to$ 11010100 $\to$与原数按位与$\to$ 00000100；
> - 而取反+1就是原数的相反数 (补码)；
>
> ```cpp
> int LowBit = x & -x; // 实际上取负操作
> ```

> [!NOTE]
>
> `int LowBit = x & -x;` 如果 `x == INT_MIN` 会发生什么？
>
> - 补码体系下，INT_MIN按位取反就是INT_MAX，而对INT_MIN取负也就是取反再+1，就是对INT_MAX+1，会导致有符号溢出；
>
> - 如果x字面上被指定为INT_MIN且开启了编译优化，则编译期就可能直接报错；
> - 如果运行时x被赋值为INT_MIN，对x取负再+1时硬件会设置溢出标志位，由于x是有符号数，编译器会插入检查溢出的指令，所以一样报错；
>
> 所以需要将x指定为无符号整数；
>
> - INT_MIN就是 100....000，取反就是0111...111，编译器是不接受有符号011...111再+1的行为的；
>
> - 但是无符号的011...111+1是完全合法的，编译器压根不会让硬件去检查标志位；
>
> - 所以最安全的写法是：
>
>   ```cpp
>   int LowBit = x & (~x + 1U); // 有符号数与无符号数作算术运算时会被强转为无符号数
>   // 或者
>   int LowBit = (unsigned int)x & -(unsigned int)x;
>   ```
>
> - 注意提取最低位1自始至终都是 x & (~x + 1) 的，x就是纯粹的二进制数，只不过：
>
>   - 补码体系下 ~x + 1 = -x；
>   - 编译器不接受有符号数的溢出；

  ```cpp
  vector<int> singleNumber(vector<int>& nums) {
      int XORAll = 0;
      for (int num : nums) {
          XORAll ^= num;
      }
      
      int LowBit = XORAll & (~XORAll + 1U);
      
      int result1 = 0;
      for (int num : nums) {
          if (num & LowBit)  
              result1 ^= num;
      }
  
      return {result1, result1 ^ XORAll};
  }
  ```

##### Problem 4

- 题目：[LeetCode - 137. 只出现一次的数字II](https://leetcode.cn/problems/single-number-ii/)；整数数组中一个元素出现 $\le m$ 次(其实只要不是 $m$ 的倍数即可)，其他元素都出现 $m$ 次；

- 本题与异或无关，但是Ⅰ和Ⅲ都看了，也顺便看看Ⅱ吧；

- 统计所有数字第 $i(i=0...31)$ 上1的频率；

  如果某位上1的频率不是 $m$ 的倍数(模 $m\ne0$)，说明特殊元素在该位上必为1；

  ```cpp
  int singleNumber(vector<int>& nums) {
      int ans = 0;
      for (int i = 0; i < 32; ++i) { // 依次统计第0到31位
          int total = 0;
          for (int num: nums) {
              total += ((num >> i) & 1); // 该位上1的频率
          }
          
          if (total % 3) { 	 // 如果不是m的倍数
              ans |= (1 << i); // ans在该位上必为1
          }
      }
      return ans;
  }
  ```

##### Problem 3

- 返回区间 $[left,right]$ 所有数按位与的结果；

  就单个位来看，一旦出现了一个0，按位与后的最终结果必然是0；

  left 到 right 的连续的数按位与，一致的高位不变，不一致的若干低位一定全是0；

  所以要找到 right 和 left 相同的那些高位，策略是不断让 right 减去最左边的1，直到left等于right；

  ```cpp
  int rangeBitwiseAnd(int left, int right) {
      while (left < right) {
          right -= (right & -right);
      }
      return right;
  }
  ```
