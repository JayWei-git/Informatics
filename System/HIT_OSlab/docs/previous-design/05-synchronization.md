# 实验五：同步与互斥

前置：实验四；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 实现计数信号量初始化、P 操作和 V 操作；资源不足时阻塞线程，释放资源时唤醒等待者；
2. 明确信号量计数与等待队列的不变量；在本实验单核环境使用保存并恢复中断状态的临界区，不无条件 `sti`；
3. 用三个信号量实现容量 10 的环形缓冲区，运行一个生产者和至少两个消费者；
4. 生产编号 0～999，记录消费结果，验证每个编号恰好消费一次；
5. 对比移除同步后的竞态，并解释先获取互斥锁再等待空槽为何可能死锁；

## 验收

- 缓冲区容量从不小于 0 或大于 10，编号无缺失、重复；
- 信号量等待必须让出 CPU，不用无限自旋伪装阻塞；
- 调整线程时间片、多次运行均通过；
- 等待队列无哑节点或虚拟头节点，说明删除队头和空队列的处理；

允许先做内核线程内使用的信号量，不要求一开始实现 POSIX 命名信号量 API；报告需写清支持范围；
