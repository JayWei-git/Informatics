# 实验七：用户进程

前置：实验六；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 每个进程拥有独立页目录、用户栈和内核栈，按设计共享内核映射；切换进程时更新 CR3 和 TSS.ESP0；
2. 从内嵌镜像或启动模块加载一个静态 ELF32 程序，按 PT_LOAD 段加载并清零 BSS；检查所有长度、偏移和地址范围；
3. 实现简化的 `spawn`、`exit`、`wait`，定义退出码和僵尸状态；
4. 分离活动栈与待回收资源，进程退出后回收用户物理页和页表；
5. 可选：增加 eager-copy 的 `fork`，先不实现写时复制；

## 验收

- 两个进程使用同一用户虚拟地址存放不同值，互不覆盖；
- 一个进程退出或异常后，其他进程能继续运行；
- 父进程等待得到正确退出码，无子进程时返回错误；
- 重复创建、退出一百次后，可用物理页数量恢复到合理基线；
- 损坏的 ELF、越界加载段和加载到内核地址的程序被拒绝；

报告要区分进程的独立地址空间与上一实验内核线程共享地址空间的差异；
