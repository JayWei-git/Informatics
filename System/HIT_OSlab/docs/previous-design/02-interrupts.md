# 实验二：异常与中断

前置：实验一；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 建立自己的平坦 GDT，加载 GDTR，重载 CS 和数据段寄存器；保留后续用户代码、用户数据和 TSS 的扩展位置；
2. 建立 256 项 IDT，为 CPU 异常 0～31 提供入口，统一构造异常现场；正确区分 CPU 自动压错误码和不压错误码的异常；
3. C 处理函数打印向量号、错误码、EIP、CS、EFLAGS；不可恢复异常打印后停机，不简单 `iret` 回到出错指令形成无限异常；
4. 重映射双 8259 PIC，把 IRQ0～15 映射到 32～47；初始化 PIT 为 100 Hz，只开放已实现的 IRQ；
5. 时钟处理函数累计 tick，向 PIC 发送正确 EOI；GDT、IDT 和 PIC/PIT 准备好后才执行 `sti`；

## 验收

- 单独运行的异常测试使用 `ud2` 产生向量 6，能显示对应 EIP，系统不重启；
- 若测试除零，使用明确的汇编 `div`，不要依赖 C 的除零未定义行为；
- 正常运行时 tick 持续增长，重复时钟中断没有因遗漏 EOI 而停住；
- 用 GDB 检查 IDTR 指向自己建立的 IDT；

## 实现边界

先使用单核和传统 PIC/PIT，暂不实现 APIC、SMP 与中断嵌套；不要在高频中断里逐次输出大量日志；汇编入口必须保护 C 使用的寄存器、设置 DF 并满足栈对齐约定；
