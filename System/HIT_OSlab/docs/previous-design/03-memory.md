# 实验三：物理内存与分页

前置：实验二；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 解析 Multiboot 内存映射；按各条目的实际长度遍历，只管理可用物理区域，不用 `mem_upper` 直接假定整片内存都可分配；
2. 按 4 KiB 页面建立位图或空闲页管理，排除低端保留内存、内核、内核栈、启动信息、模块及位图自身；
3. 实现页分配和回收，检测越界、重复释放；
4. 建立非 PAE 的二级页表，先恒等映射当前代码、栈、页表以及 VGA，加载 CR3 并打开 CR0.PG；
5. 实现映射、取消映射及 TLB 失效处理，为一个虚拟地址映射物理页并读写；
6. 故意访问未映射地址，在缺页处理函数打印 CR2 和错误码；

## 验收

- 连续分配的活动页互不重叠，释放后可以再次使用；
- 分配器不会返回任何保留区域；改变 QEMU 内存大小仍能正确初始化；
- 开分页后串口输出继续正常；GDB 能核对 PDE、PTE 与计算得到的物理地址；
- 缺页日志的 CR2 与故意访问的地址相同；

记录一组虚拟地址、页目录索引、页表索引、页内偏移及最终物理地址；此阶段不要求交换分区、按需分页或高级堆分配器；
