# 实验四：内核线程与调度

前置：实验二、三；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 定义线程控制块，至少保存 ID、状态、内核栈位置、运行 tick 和调度链关系；链表不得使用哑节点或虚拟头节点；
2. 实现独立线程栈及初始现场，线程函数返回后应进入统一退出路径；
3. 先实现主动 `yield` 和基于内核栈的软件切换，保存符合 ABI 的被调用者保存寄存器；
4. 增加轮转时间片和时钟抢占；就绪队列修改需要临界区保护；
5. 增加 idle 线程、阻塞、唤醒和退出状态；不得释放当前仍在使用的栈；
6. 输出 `线程ID、状态事件、tick` 的轨迹，比较不同时间片下的行为；

## 验收

- 至少三个线程各自维护局部计数，反复切换后值仍正确；
- 存在不主动调用 `yield` 的线程时，其他线程仍能获得 CPU；
- 线程正常返回不崩溃，退出线程不会继续进入就绪队列；
- 所有工作线程阻塞时 idle 能运行，被唤醒后能继续调度；

说明主动切换和从中断返回时恢复现场的区别；本实验不要求跨核调度，也不把单纯交替打印等同于抢占调度已完成；
