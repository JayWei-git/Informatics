# 实验六：用户态与系统调用

前置：实验二、三、四；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 增加 DPL=3 的用户代码和数据段，建立 TSS，设置有效的 SS0、ESP0，使用 `ltr` 加载任务寄存器；TSS 用于特权级栈切换，不要求硬件任务切换；
2. 为用户代码和栈建立用户可访问映射，内核页保持 supervisor 权限；通过构造 `iret` 现场进入 Ring 3；
3. 建立 DPL=3 的 `int 0x80` 门，统一保存现场并分发系统调用；
4. 约定 EAX 为调用号、EBX/ECX/EDX 为参数，EAX 返回结果；实现 `write`、`gettid`、`yield`；
5. 对用户指针范围、长度、溢出和页面权限进行检查，再从用户区复制数据；

## 验收

- 用户程序显示的 CS 特权级为 3，系统调用处理程序运行在 0；
- 用户程序能通过 `write` 输出文字，通过 `gettid` 获取 ID；
- 非法调用号返回错误，不跳转任意地址；
- 传入内核地址、未映射指针、跨页无效缓冲区不会破坏内核；
- 用户执行特权指令会产生异常，内核能报告并隔离该任务；

这个阶段只需简单静态用户程序，暂不实现完整 libc；不要用 Ring 0 中的 `int 0x80` 调用冒充用户态验收；
