# 实验八：设备与文件接口

前置：实验二、六、七；本文件是任务书，当前代码尚未实现本实验；

## 任务

1. 增加 PS/2 键盘 IRQ1，解析基本按键、换行和退格，使用输入队列把中断处理与读操作分开；
2. 实现终端行输入和阻塞读取，字符输出复用现有控制台；
3. 建立小型只读内存文件系统，提供 `open`、`read`、`close` 和每进程文件描述符表；
4. 实现 `/proc/tasks`，读取时生成当前任务信息，而不是返回写死字符串；
5. 编写用户态简单 shell，至少支持 `help`、`ls`、`cat`、`ps` 和启动内置用户程序；
6. 可选：用 F12 开关把终端输出字母显示为星号，保留向普通文件写入时的原始内容；

## 验收

- 按键中断能持续处理，空输入时读取线程阻塞，输入后被唤醒；
- 同一文件分多次读取仍正确，到文件末尾返回 0；
- 无效文件描述符、路径、用户缓冲区得到错误返回；
- `ps` 输出随进程创建、退出而变化；
- shell 位于用户态，不能直接访问内核内部数据结构；

基础版不要求真实磁盘驱动、可写磁盘文件系统或完整 POSIX 兼容；后续可以再增加 virtio-blk 等设备实验；
