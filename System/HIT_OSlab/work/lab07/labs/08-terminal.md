# 实验八：终端设备控制

## 要学什么

按键扫描码、IRQ1、中断应答、应用输出和控制台显示的关系，怎样只改变终端显示而不改变应用原始数据；

## 原始文件和步骤

```bash
make prepare LAB=08
cd work/lab08
make lab-test LAB=08
```

补齐 `kernel/console.c` 的 `console_filter_toggle`；初始正常，F12 按下一次打开过滤，再按一次恢复；a～z、A～Z 显示成星号，数字、标点、换行保持；

1. 跟踪 `isr33 → interrupt_dispatch → 读取端口0x60 → 扫描码0x58 → console_filter_toggle`；说明按下码、释放码及 EOI；
2. 在统一输出点过滤，不能修改用户传来的字符串或 proc 的内部数据；VGA 与串口显示应一致；
3. 阅读自动测试：它通过 QEMU monitor 注入真实 F12 按键，而不是直接调用你的切换函数；
4. 执行 `make run DEMO=terminal`，可另用 monitor 的 sendkey f12 或可选图形窗口进行人工验证；终端键盘 F12 不会自动变成 PS/2 扫描码；

## 验收与思考

测试应观测 `AbC-123! → ***-123! → AbC-123!`；解释为什么用户缓冲区和文件内容不应一起变化，以及若要过滤所有 write 调用，应改在哪个层次；本实验不要求重写完整键盘布局或串口驱动；
