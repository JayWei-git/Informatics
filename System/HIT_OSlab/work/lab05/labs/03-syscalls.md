# 实验三：系统调用

## 要学什么

用户态如何进入内核、调用号与中断向量的区别、用户指针检查、返回值和错误处理；

## 原始文件和步骤

```bash
make prepare LAB=03
cd work/lab03
make
make lab-test LAB=03
```

开始时对应测试应失败；补齐 `kernel/runtime.c` 的 `sys_iam`、`sys_whoami`；参考设施已经提供 Ring 3、TSS 特权栈、中断入口和用户调用包装；

- iam 保存用户字符串，最多 23 字符，不计结尾零；成功返回长度；过长返回 -22，非法指针返回 -14，失败不改变此前保存的名字；
- whoami 将名字和结尾零复制到用户缓冲区；容量不足返回 -22，非法或不可写目标返回 -14，成功返回不含结尾零的长度；
- 不能直接相信指针，使用基线 `user_range`，检查跨页、加法溢出、页存在和用户/写权限；

跟踪 `user_program → int 0x80 → interrupt_common → interrupt_dispatch → sys_iam → iret`；调用号放在 EAX，参数在 EBX/ECX/EDX，返回值在 EAX；原课 errno 包装由本工程直接负错误码 ABI 代替，自己增加 errno 包装作为扩展；

## 验收与思考

固定测试覆盖正常名字、过长名字、小缓冲区、内核地址和未知调用号；补充空名字、恰好 23 字符、空指针、跨页目标的测试；GDB 证明调用前 CS&3=3、处理函数内 CS&3=0，并解释为什么 TSS.ESP0 必须有效；
