# 实验七：地址映射与共享

## 要学什么

从段选择子到线性地址、从页目录/页表到物理页；相同虚拟地址可以指向不同物理页，也可以被显式映射到同一物理页；

## 原始文件和步骤

```bash
make prepare LAB=07
cd work/lab07
make lab-test LAB=07
```

补齐 `kernel/runtime.c` 的 `shared_attach`；简化 shmget 仅支持 key=7、0<size≤4096，返回 shmid=1；shmat 必须检查 ID、设置当前任务共享页 PTE，调用 invlpg，返回 0x40000000；不能只返回常量而不改页表；

1. 执行 `make debug-pipe DEMO=address`，增加 user_program 断点并继续；该任务把私有地址 0x40001000 设置为 0x12345678 后循环等待它变成 0；
2. 读取用户 CS，检查 GDT 描述符基址，计算线性地址；本基线采用平坦 GDT，不使用 LDT；
3. 从 CR3 查 PDE，再查 PTE，计算页内偏移和物理地址；不要直接用变量名代替手工推导；
4. 通过内核恒等映射中该物理页的别名，把值改为 0，继续运行，观察用户任务退出；说明为何该别名的数值地址与物理地址一致；
5. 对 private 演示的两个任务重复页表检查，证明同一虚拟地址对应不同物理页；
6. 对 shared 演示检查 PTE，证明不同 CR3 下共享虚拟地址指向相同物理页，并运行生产者消费者；

## 验收与思考

host-test、shared、private 和 fault 案例通过；fault 由用户态读取内核地址主动触发 PF，内核应隔离并报告，不能把所有异常都当成功；记录至少一条完整手工地址翻译；重复启动后比较地址是否变化及原因；

当前共享物理页由基线静态预留，扩展为多个 key、动态分配/回收属于加分项；
