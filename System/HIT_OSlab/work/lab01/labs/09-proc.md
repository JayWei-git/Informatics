# 实验九：proc 文件接口

## 要学什么

让内核实时状态通过文件接口读出，理解生成型节点、文件描述符、读取偏移、短读与 EOF；

## 原始文件和步骤

```bash
make prepare LAB=09
cd work/lab09
make lab-test LAB=09
```

补齐 `kernel/runtime.c` 的 `proc_snapshot`；输出头和每个任务的 ID、状态、角色、CPU tick、切换次数，不能返回写死的进程列表；缓冲区为 1024 字节，最多 12 个任务，必须证明不会越界；返回字节数，不计终止符；

1. 阅读 proc_open 的路径检查和新快照生成，proc_read 的偏移维护、用户区复制，以及 close 的描述符失效；
2. 用户程序每次只读 17 字节，多次读取应还原完整内容，读完返回 0，关闭后再次读取返回 -9；
3. 在 shell 执行 `ps`、运行一个演示后再查看，比较状态和统计变化；
4. 把路径、节点类型和内容生成函数整理成可扩展的节点分发表，再增加 /proc/meminfo，避免每增加节点就在所有 read 路径中散布特判；

## 验收与思考

固定测试证明生成内容、分次读取、EOF 和关闭行为；自行提交新节点及未知路径、无效用户缓冲区测试；说明打开时快照与每次 read 重新生成的差别，以及内容长度变化时如何避免偏移错乱；

这里提供的是极小只读 proc 接口，不是完整磁盘文件系统；原课涉及的 Minix inode/mknod 由节点类型与分发表的设计练习替代，报告必须比较两者的对应关系；
